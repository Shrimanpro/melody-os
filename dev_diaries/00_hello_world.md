# The Start

When I first started this project, the plan was to turn my Raspberry Pi into a home music player. That's still the goal, but I've moved it over to an old computer instead. The main reason I switched is because the Raspberry Pi is so portable and can do so many different things. It felt like a waste to tie it down. My old PC is the exact opposite; heavy and stuck in one place. So it’s perfect for this.

An added bonus is that the PC uses x86_64 architecture instead of ARM. I’ve used ARM for small things, but I’ve worked a lot more with x86_64, so it’s much more comfortable for a project this size.



# The Journey

Figuring out *how* to build this took way longer than deciding what to build. Once I finally settled on an approach, I started coding. Honestly, writing the code wasn't as hard as I expected because there's so much documentation online. I learned a lot really fast. But actually getting it to run? That was a different story.

Even though the code was tiny, it took me forever. Half the time it wouldn't even compile. When it finally did compile, it wouldn't work right. Eventually, I got "Hello World" to print on the screen. It might look super simple, but for me, it took a ton of continuous dedication to get there.
